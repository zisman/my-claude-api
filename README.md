# מערכת ניהול מועדון מצנחי רחיפה

מערכת ניהול מקיפה למועדון מצנחי רחיפה עם 11 מודולים + עוזר AI מבוסס Claude.

## מודולים

1. **שיווק ופרסום** — ניהול לידים, קמפיינים, תובנות AI
2. **לקוחות (CRM)** — ניהול חברי מועדון, היסטוריה, תעודות
3. **תלמידים** — מעקב התקדמות, קורסים, ציוני מבחנים, ניתוח AI
4. **טיסות חוויה ואירועים** — הזמנות, כתבי ויתור, תשלומים
5. **ספקים** — מסד נתונים, הזמנות, דירוגים
6. **ציוד** — מלאי ציוד מועדון ואישי, היסטוריית שימוש
7. **תחזוקה** — רשומות ותחזיות AI (תיקון, ריענון, החלפה)
8. **מזג אוויר** — נתוני Open-Meteo בזמן אמת + ניתוח בטיחות AI
9. **קהילה** — פוסטים, תגובות, הודעות
10. **מסלולי טיסה** — מאגר מסלולים עם ביקורות ודירוגים
11. **שיעורים אונליין** — מודולי לימוד, חידונים, מעקב התקדמות
12. **עוזר AI** — צ'אט streaming עם Claude Opus 4.7

## טכנולוגיות

- **Backend**: Node.js + Express + SQLite (better-sqlite3)
- **Frontend**: React + Vite + Tailwind CSS
- **AI**: Claude Opus 4.7 עם adaptive thinking + prompt caching
- **מזג אוויר**: Open-Meteo API (ללא מפתח API)

## התקנה והרצה

### Backend

```bash
cd backend
npm install
cp .env.example .env
# ערוך .env והוסף: ANTHROPIC_API_KEY=your_key
npm run dev
```

שרת: `http://localhost:3001`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

ממשק: `http://localhost:5173`
